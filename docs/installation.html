2. Installation et exécution

Prérequis

  • Python 3.11 ou supérieur, avec pip.
  • Node.js (avec npm) — utilisé pour construire l'interface web.

Démarrage rapide (recommandé)

Deux scripts à la racine du dépôt installent les dépendances puis lancent le serveur en une seule étape :

TerminalCommande
PowerShell./install-and-run.ps1
Invite de commandes (cmd)install-and-run.bat

Ces scripts, dans l'ordre :

  1. Vérifient que Python et Node/npm sont disponibles dans le PATH.
  2. Installent le paquet Python lumaflow en mode éditable (pip install -e .).
  3. Installent les dépendances npm de l'interface web si nécessaire, puis la construisent (npm run build).
  4. Lancent le serveur (lumaflow), qui ouvre automatiquement votre navigateur sur http://127.0.0.1:8000.

La fenêtre de terminal reste occupée par le serveur tant qu'il tourne ; fermez-la (ou faites Ctrl+C) pour l'arrêter. Relancer le script plus tard réinstalle/reconstruit rapidement (les dépendances déjà présentes ne sont pas retéléchargées) puis relance le serveur.

Installation manuelle

Si vous préférez ne pas utiliser les scripts, les mêmes étapes à la main, depuis la racine du dépôt :

pip install -e .
cd web
npm install
npm run build
cd ..
lumaflow

La commande lumaflow (installée par pip install -e .) est le point d'entrée de production : elle construit l'interface web si besoin (au tout premier lancement seulement — après toute modification du code de web/src/, reconstruisez avec npm run build avant de relancer), puis démarre le serveur et ouvre le navigateur.

Mode développement

Pour travailler sur l'interface avec rechargement à chaud, deux serveurs séparés :

# Terminal 1 — API FastAPI seule (sans servir le build web)
lumaflow-api

# Terminal 2 — serveur de développement Vite (rechargement à chaud)
cd web
npm run dev
