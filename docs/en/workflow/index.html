4. Workflow step details

This section details, row by row, exactly what each thumbnail does, then each manual setting available in that row's Zoom. Manual settings are grouped exactly as in the interface (Zoom's "Manual settings" accordion): Strength / Tone / Colour / Texture & Grain for Film, Bleach Bypass, Monochrome and B&W (B&W adds a Filter group); Exposure & Tone / Colour / Texture & Sharpness / Bloom & Softness / Finishing for Light.

A note on the before/after images: each manual setting is illustrated in isolation — the slider is pushed to an extreme value on a fixed base (a neutral preset or a reference preset, depending on the setting), with every other value left at its default, so that the image shows only the contribution of THAT one setting, without blending it with the others. Bleach Bypass and B&W share exactly the same engine and the same setting identifiers as Film (lumaflow/addons/builtin/film.py, a single module for all three rows): rather than duplicating pixel-for-pixel identical images under a different heading, the Bleach Bypass page links to the Film page's illustrations, and the B&W page only illustrates the 2 settings that are specific to it (the colored filter). Two settings on the Light row (hsl_saturation_scale/hsl_luminance_scale) are flagged without an image: as of today, none of the shipped presets populate the internal tables they're meant to modulate, so they're inert regardless of the selected preset (reserved for a future hue-calibrated look) — a before/after would be misleading since it would never show any difference.
