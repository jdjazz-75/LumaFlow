2. Installation and running

Prerequisites

  • Python 3.11 or later, with pip.
  • Node.js (with npm) — used to build the web interface.

Quick start (recommended)

Two scripts at the root of the repository install the dependencies and then launch the server, in a single step:

TerminalCommand
PowerShell./install-and-run.ps1
Command Prompt (cmd)install-and-run.bat

These scripts, in order:

  1. Check that Python and Node/npm are available on the PATH.
  2. Install the lumaflow Python package in editable mode (pip install -e .).
  3. Install the web interface's npm dependencies if needed, then build it (npm run build).
  4. Launch the server (lumaflow), which automatically opens your browser at http://127.0.0.1:8000.

The terminal window stays occupied by the server for as long as it runs; close it (or press Ctrl+C) to stop it. Running the script again later quickly reinstalls/rebuilds (dependencies already present aren't re-downloaded) and then relaunches the server.

Manual installation

If you'd rather not use the scripts, here are the same steps by hand, from the root of the repository:

pip install -e .
cd web
npm install
npm run build
cd ..
lumaflow

The lumaflow command (installed by pip install -e .) is the production entry point: it builds the web interface if needed (only on the very first launch — after any change to the code in web/src/, rebuild with npm run build before relaunching), then starts the server and opens the browser.

Development mode

To work on the interface with hot reload, run two separate servers:

# Terminal 1 — FastAPI API only (does not serve the web build)
lumaflow-api

# Terminal 2 — Vite development server (hot reload)
cd web
npm run dev
